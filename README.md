# 地平线 · 全球股市日报与个股收盘复盘

正式公网网址：

<https://lwj888lwj.github.io/stock-review-site/>

页面可直接在电脑或手机浏览器打开，不需要密码，也不要求电脑保持开机。

## 安装为 App

- iPhone / iPad：用 Safari 打开网站，点击“分享”，选择“添加到主屏幕”。
- Android：用 Chrome 打开网站，点击右上角菜单，选择“安装应用”或“添加到主屏幕”。
- 电脑 Chrome / Edge：点击地址栏中的安装图标，或使用页面右上角的“安装 App”。

安装后会有独立应用图标，并以全屏模式打开。网站内容更新后，App 会自动加载新版本，无需重新下载。

## 当前功能

- A 股、港股、美股指数行情概览。
- 汇率、A50 期指、原油、黄金、铜和美债收益率观察。
- 西部矿业（601168.SH）、中国西电（601179.SH）、华之杰（603400.SH）收盘复盘。
- 次日开盘情景、波动等级、支撑压力、基本面、风险和术语白话解释。
- 页面打开时同步最新可得行情，交易时段每 60 秒尝试刷新一次。

## 行情与更新时间

指数和个股行情通过腾讯行情接口在浏览器端更新。页面会保留最近一次有效快照，接口暂时不可访问时不会用随机数字或虚构行情代替。

- A 股和港股显示收盘行情，并保留行情源时间。
- 美股根据交易时段显示盘中或最近收盘行情。
- 汇率、商品和期指在页面打开时同步。
- 美债收益率目前为最近可得数据，不作为交易所级实时报价。

日报文字、个股基本面和开盘情景属于基于快照的规则分析，并非交易所级实时投顾服务。开盘概率、波动区间、支撑位和压力位均不保证未来结果。

## 后续添加股票

在 `app.js` 顶部的 `stocks` 数组中追加股票对象，并在 `tickerMap`、`liveQuoteSymbols` 中补上对应代码，即可加入股票池、复盘页和预测记录。

## 发布方式

仓库使用 GitHub Pages 的 `main` 分支根目录发布。提交到 `main` 后，GitHub 会自动重新部署网页。
