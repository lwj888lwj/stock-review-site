# 地平线 · 个股收盘复盘

浅色财经情报风的可运行网站原型，内置：

- 西部矿业（601168.SH）
- 中国西电（601179.SH）
- 华之杰（603400.SH）

## 打开方式

直接打开 `index.html` 即可。页面不依赖外部字体、图表库或网络接口。

## 手机访问

1. 确保手机和 Mac 连接同一个 Wi-Fi。
2. 双击 `start-phone-access.command`。
3. 终端窗口会显示形如 `http://192.168.x.x:8080/` 的地址。
4. 在手机浏览器中打开该地址。

服务开启期间需要保持 Mac 醒着，并保持启动脚本的终端窗口开启。局域网网址只适合临时查看；如需外网访问，需要将网站发布到 Sites 等公网托管平台。

## 后续添加股票

在 `app.js` 顶部的 `stocks` 数组中追加一个股票对象。股票池、复盘详情、明日开盘情景、技术指标、基本面和预测记录会自动更新。

建议后续接入：

1. 每个交易日收盘后的实时行情和分钟数据。
2. 历史价格、成交量和财务数据结构化存储。
3. 开盘预测与实际开盘价自动对照。
4. 自选股列表、价格提醒和后台定时任务。
